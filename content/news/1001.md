## 方式一：电子邮件

不熟悉 GitHub 也完全没问题，把稿件发到下面任一邮箱：

- yes-reply@遂宁奶龙大学.lol
- t@tchirek.top

邮件请写明标题、作者（或署名单位），正文可直接写在邮件里，也可以作为附件。配图请作为附件单独发送，不要只粘贴在正文里。

## 方式二：GitHub

会用 GitHub 的同学，直接向仓库提交 PR，或者在 Issues 里留下稿件 [![GitHub SNNLU/snnlu-web](/img/github-badge.svg)](https://github.com/SNNLU/snnlu-web)，我们会尽快处理。

- 提交 PR：把文章放进 content/news/ 下，用 数字.md 命名，文件名不能与已有文章重复
- 文章头部写明 title、date、folder、source 四项，格式见仓库 README
- 配图放进 public/img/，正文用 ![](/img/文件名.jpg) 引用
- 不会写头部也没关系：在 SNNLU/snnlu-web 的 Issues 里贴出正文，图片直接拖进去即可
